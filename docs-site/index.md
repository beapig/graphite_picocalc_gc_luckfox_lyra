# PicoCalc GraphCalc

A TI-83/84-inspired graphing calculator, running on the [ClockworkPi
PicoCalc](https://www.clockworkpi.com/picocalc) handheld — natural math
display, function/parametric/polar/sequence graphing, statistics,
matrices, and complex numbers, open-source and built from a Raspberry Pi
Pico or Pico 2 module.

This site is the user guide: how to build and flash the firmware, how to
use the calculator, and reference material (function catalog, key
reference, syntax notes) generated straight from the firmware source so
it can't drift out of date.

## What this is not

This is the **user** guide. Developer/spec/architecture material (phase
contracts, decisions log, hardware bring-up notes) lives in the main
repository's `docs/` tree and is not republished here — see the
project's `AGENTS.md` and `docs/` if you're contributing to the
firmware itself.
